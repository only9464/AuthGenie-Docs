## 接口说明

已登录用户可以创建新的团队，创建者自动成为团队所有者（owner）。团队名称在同一用户下必须唯一。

## 请求

**URL:** `/api/user/team/create`

**方法:** `POST`

**Content-Type:** `application/json`

## 请求头

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Cookie | string | 是 | session_id，HttpOnly Cookie |
| Content-Type | string | 是 | 必须为 application/json |

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 团队名称 |

## 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| team | object | 团队信息 |
| team.id | number | 团队 ID |
| team.name | string | 团队名称 |
| team.ownerUserId | number | 所有者用户 ID |
| team.status | string | 团队状态：active/disabled |
| team.createdAt | number | 创建时间戳 |
| team.updatedAt | number | 更新时间戳 |
| role | string | 用户在团队中的角色：owner |

## 响应示例

```json
{
  "team": {
    "id": 1,
    "name": "My Team",
    "ownerUserId": 1001,
    "status": "active",
    "createdAt": 1773478150000,
    "updatedAt": 1773478150000
  },
  "role": "owner"
}
```

## 错误码

| 状态码 | 错误码 | 说明 |
|--------|--------|------|
| 200 | SUCCESS | 创建成功 |
| 400 | INVALID_PARAMETERS | 参数无效 |
| 401 | UNAUTHORIZED | 未授权 |
| 409 | TEAM_NAME_EXISTS | 团队名称已存在 |
| 500 | DATABASE_ERROR | 数据库错误 |

## 实现细节

1. 验证用户登录状态
2. 检查团队名称是否已存在
3. 创建团队记录
4. 添加用户为团队所有者（teamMembers 表）
5. 记录操作日志
