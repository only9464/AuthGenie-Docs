## 接口说明

为指定项目批量生成许可证密钥。支持自定义密钥长度和字符类型（数字/小写字母/大写字母）。

**生成限制：**
- 单次最多生成 1000 个许可证
- 密钥长度必须 >= 所选字符类型数量
- 至少选择一种字符类型

## 请求

**URL:** `/api/user/license/batch`

**方法:** `POST`

**Content-Type:** `application/json`

## 请求头

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Cookie | string | 是 | session_id，HttpOnly Cookie |
| Content-Type | string | 是 | 必须为 application/json |

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| projectId | number | 是 | 项目 ID |
| count | number | 是 | 生成数量，最大 1000 |
| length | number | 是 | 密钥长度 |
| includeDigits | boolean | 是 | 是否包含数字 (0-9) |
| includeLowercase | boolean | 是 | 是否包含小写字母 (a-z) |
| includeUppercase | boolean | 是 | 是否包含大写字母 (A-Z) |

## 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| generatedAt | number | 生成时间戳 |
| projectId | number | 项目 ID |
| platform | string | 项目平台（windows/macos/linux/android/ios/harmonyos） |
| count | number | 生成数量 |
| length | number | 密钥长度 |
| includeDigits | boolean | 是否包含数字 |
| includeLowercase | boolean | 是否包含小写字母 |
| includeUppercase | boolean | 是否包含大写字母 |
| licenses | array | 生成的许可证列表 |
| licenses[].licenseKey | string | 许可证密钥 |
| licenses[].status | string | 许可证状态：pending |

## 响应示例

```json
{
  "generatedAt": 1773478150000,
  "projectId": 1,
  "platform": "windows",
  "count": 10,
  "length": 16,
  "includeDigits": true,
  "includeLowercase": true,
  "includeUppercase": true,
  "licenses": [
    { "licenseKey": "aB3cD4eF5gH6iJ7k", "status": "pending" },
    { "licenseKey": "xY9zA8bC7dE6fG5h", "status": "pending" }
  ]
}
```

## 错误码

| 状态码 | 错误码 | 说明 |
|--------|--------|------|
| 200 | SUCCESS | 生成成功 |
| 400 | INVALID_PARAMETERS | 参数无效 |
| 401 | UNAUTHORIZED | 未授权 |
| 403 | FORBIDDEN | 无权限访问该项目 |
| 403 | PROJECT_DISABLED | 项目已被停用 |
| 404 | PROJECT_NOT_FOUND | 项目不存在 |
| 500 | DATABASE_ERROR | 数据库错误 |

## 实现细节

1. 验证用户登录状态
2. 验证请求参数（projectId、count、length、字符类型）
3. 检查项目是否存在且状态正常
4. 验证用户是否有权限访问该项目
5. 根据项目平台选择对应的许可证表
6. 批量生成唯一许可证密钥
7. 分块插入数据库（避免参数超限）
8. 记录操作日志

## 密钥生成算法

- 使用 crypto.getRandomValues() 生成随机数
- 确保至少包含所选的每种字符类型
- 使用 Fisher-Yates 洗牌算法打乱字符顺序
- 检查密钥唯一性，如有重复则重新生成
