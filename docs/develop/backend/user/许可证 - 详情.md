## 接口说明

获取指定许可证的详细信息，包括绑定状态、校验历史等。

## 请求

**URL:** `/api/user/license/detail`

**方法:** `GET`

## 请求头

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Cookie | string | 是 | session_id，HttpOnly Cookie |

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| licenseId | number | 是 | 许可证 ID（Query 参数） |

## 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| license | object | 许可证详细信息 |
| license.id | number | 许可证 ID |
| license.projectId | number | 所属项目 ID |
| license.licenseKey | string | 许可证密钥 |
| license.status | string | 状态 |
| license.createdAt | number | 创建时间戳 |
| license.firstUsedAt | number | 首次使用时间戳 |
| license.lastUsedAt | number | 最后校验时间戳 |
| license.bound | boolean | 是否已绑定设备 |
| license.hardware | object | 绑定的硬件信息（如已绑定） |


## 错误码

| 状态码 | 错误码 | 说明 |
|--------|--------|------|
| 200 | SUCCESS | 查询成功 |
| 400 | INVALID_PARAMETERS | 参数无效 |
| 401 | UNAUTHORIZED | 未授权 |
| 403 | FORBIDDEN | 无权限访问该许可证 |
| 404 | LICENSE_NOT_FOUND | 许可证不存在 |
| 500 | DATABASE_ERROR | 数据库错误 |
