## 接口说明

删除指定的项目。删除项目会同时删除该项目下的所有许可证。

## 请求

**URL:** `/api/user/project/delete`

**方法:** `DELETE`

## 请求头

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Cookie | string | 是 | session_id，HttpOnly Cookie |

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| projectId | number | 是 | 项目 ID（Query 参数） |

## 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| success | boolean | 是否成功 |

## 响应示例

```json
{
  "success": true
}
```

## 错误码

| 状态码 | 错误码 | 说明 |
|--------|--------|------|
| 200 | SUCCESS | 删除成功 |
| 400 | INVALID_PARAMETERS | 参数无效 |
| 401 | UNAUTHORIZED | 未授权 |
| 403 | FORBIDDEN | 无权限删除该项目 |
| 404 | PROJECT_NOT_FOUND | 项目不存在 |
| 500 | DATABASE_ERROR | 数据库错误 |
