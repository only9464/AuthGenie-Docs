项目名称： AuthGenie 许可证管理系统
开发单位： 毕业设计项目

一、引言

1.1 目的

本需求分析说明书旨在明确 AuthGenie 许可证管理系统的功能需求、非功能需求、用户界面需求和运行环境需求，为系统设计、开发实现、测试验证提供依据。通过本文档，项目组成员及相关利益方能够对系统需求达成一致理解。

读者对象：

  • 项目开发团队（开发者、测试人员）
  • 项目管理人员
  • 毕业设计指导教师
  • 项目评审专家

1.2 背景

项目要素说明
项目名称AuthGenie 许可证管理系统
项目委托方毕业设计项目
项目开发方个人独立开发
项目开发背景随着软件产业的发展，软件许可证管理成为软件保护的重要手段。传统的许可证管理方案存在部署复杂、成本高、跨平台支持不足等问题。本项目旨在构建一个基于 Cloudflare Workers 边缘计算的现代化许可证管理系统，提供低成本、高性能、多平台支持的许可证管理解决方案。
项目开发内容开发一个完整的许可证管理系统，包括：用户管理、团队管理、项目管理、许可证生成与校验、多平台 SDK 支持（Windows/macOS/Linux/Android/iOS/HarmonyOS）、三级权限管理（超级管理员/管理员/普通用户）、审计日志等功能模块。

二、软件系统描述

2.1 软件介绍

软件名称

AuthGenie 许可证管理系统

实现目标

  1. 提供一个完整的软件许可证管理解决方案
  2. 支持六大操作系统平台的许可证校验
  3. 实现三级权限管理体系
  4. 提供低延迟、高可用的服务
  5. 控制成本，适合中小型软件企业使用

开发背景

传统许可证管理方案存在以下问题：

  • 部署复杂，需要自建服务器和数据库
  • 成本高，服务器、CDN、运维费用昂贵
  • 跨地域访问延迟高，用户体验差
  • 扩展困难，需要手动增加服务器
  • 多平台支持不足，各平台实现不一致

AuthGenie 采用 Cloudflare Workers 边缘计算架构，解决上述问题。

适用领域

  • 中小型软件企业的许可证管理
  • 跨平台桌面应用的授权验证
  • 移动应用的付费功能解锁
  • SaaS 服务的订阅管理
  • 软件毕业设计的参考实现

不适用领域

  • 超大规模企业级应用（日活 > 100 万）
  • 需要完全离线校验的场景
  • 对数据主权有严格要求的场景（数据必须存储在特定国家/地区）
  • 需要深度定制数据库的场景

应当包含的内容

  • 用户注册与登录
  • 团队管理
  • 项目管理
  • 许可证生成与管理
  • 许可证校验 API
  • 三级权限管理
  • 审计日志
  • Web 管理后台（用户端、管理员端、超级管理员端）
  • 客户端 SDK（六大平台）

不包含的内容

  • 支付系统集成（许可证销售）
  • 邮件通知系统
  • 短信验证
  • 第三方登录（微信、GitHub 等）
  • 移动端 App（仅提供 SDK）

优先级高
输入username（字符串，2-20 字符）, password（字符串，6-32 字符）
操作序列1. 用户访问注册页面
2. 输入用户名和密码
3. 点击注册按钮
4. 系统验证输入
5. 检查用户名是否已存在
6. 创建用户记录
7. 返回注册成功
输出
补充说明用户名必须唯一，密码明文存储（后续版本改进为哈希）

3.1.2 用户登录 (F-USER-002)

项目内容
名称、标识符用户登录，F-USER-002
功能描述验证用户身份，返回 JWT Token
优先级高
输入username（字符串）, password（字符串）

UI-NF-006 一致性所有页面应保持统一的视觉风格和交互模式
UI-NF-007 可访问性支持键盘导航，符合 WCAG 2.1 AA 标准（后续版本实现）
